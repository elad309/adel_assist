מדריך: איך להשיג את הערכים הדרושים לדמו של Adel Assistant
=========================================================

צריך למלא בקובץ .env של הפרויקט 3 ערכים בלבד:

1. TELEGRAM_BOT_TOKEN
2. ADEL_ADMIN_TELEGRAM_ID
3. OPENROUTER_API_KEY

המדריך הזה מסביר איך להשיג אותם.


חלק א': יצירת בוט בטלגרם וקבלת TELEGRAM_BOT_TOKEN
--------------------------------------------------

1. פתח את Telegram.

2. בשורת החיפוש חפש:
   @BotFather

3. ודא שזה הבוט הרשמי של Telegram.
   בדרך כלל השם הוא BotFather ויש לו סימון רשמי.

4. פתח שיחה עם BotFather ולחץ Start, או שלח:
   /start

5. שלח את הפקודה:
   /newbot

6. BotFather יבקש שם לבוט.
   אפשר לכתוב למשל:
   Adel Assistant Demo

7. BotFather יבקש username לבוט.
   חשוב: username חייב להסתיים ב-bot.
   דוגמאות:
   adel_assistant_demo_bot
   brainbox_adel_demo_bot

8. אם השם פנוי, BotFather יחזיר הודעה עם token.
   זה ייראה בערך כך:
   1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

9. זה הערך שצריך לשים ב-.env:
   TELEGRAM_BOT_TOKEN=1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

חשוב:
- לא לפרסם את ה-token.
- לא לשלוח אותו בצ'אט ציבורי.
- אם הוא נחשף, אפשר לבקש מ-BotFather לעשות revoke token.


חלק ב': קבלת ה-Telegram ID שלך עבור ADEL_ADMIN_TELEGRAM_ID
-----------------------------------------------------------

1. בטלגרם, חפש:
   @userinfobot

2. פתח את הבוט ולחץ Start, או שלח:
   /start

3. הבוט יחזיר פרטים על המשתמש שלך.
   חפש שורה בשם:
   Id
   או:
   Your user ID

4. המספר הזה הוא ה-Telegram ID שלך.
   לדוגמה:
   123456789

5. שים אותו בקובץ .env כך:
   ADEL_ADMIN_TELEGRAM_ID=123456789

למה זה חשוב?
- המשתמש עם ה-ID הזה יזוהה כבעלים של העסק.
- בפעם הראשונה שתשלח /start לבוט של Adel, הוא יפתח עבורך business מקומי ב-SQLite.
- אם שמת ID לא נכון, הבוט לא יזהה אותך כבעלים.

אם טעית ב-ID וכבר הרצת את הדמו:
1. עצור את הבוט.
2. מחק את קובץ ה-DB:
   data/adel-demo.db
3. תקן את ADEL_ADMIN_TELEGRAM_ID ב-.env.
4. הפעל שוב את הבוט.


חלק ג': קבלת OPENROUTER_API_KEY
-------------------------------

1. פתח בדפדפן:
   https://openrouter.ai/keys

2. התחבר לחשבון OpenRouter שלך.

3. צור API key חדש.

4. העתק את המפתח.
   הוא ייראה בערך כך:
   sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

5. שים אותו בקובץ .env כך:
   OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

6. ודא שיש קרדיט פעיל בחשבון OpenRouter.
   בלי קרדיט, ה-RAG והטיוטות לא יעבדו.


חלק ד': איך למלא את קובץ .env
-----------------------------

1. פתח טרמינל בתיקיית הפרויקט:
   cd "C:\Code\BrainboxAI\1 - projects\Adel Assistant"

2. צור קובץ .env מהתבנית:
   copy .env.demo .env

3. פתח את הקובץ .env בעורך טקסט.

4. מלא רק את שלושת השדות האלה:

   OPENROUTER_API_KEY=...
   TELEGRAM_BOT_TOKEN=...
   ADEL_ADMIN_TELEGRAM_ID=...

5. ודא ששאר ההגדרות נשארות כך לדמו:

   ADEL_STORAGE_BACKEND=sqlite
   SQLITE_DB_PATH=./data/adel-demo.db
   OPENROUTER_MODEL=anthropic/claude-sonnet-4.5
   CALENDAR_BACKEND=stub

6. שמור את הקובץ.


חלק ה': בדיקה שהכול מוכן
------------------------

1. בתיקיית הפרויקט הרץ:
   npm run typecheck

2. אחר כך:
   npm run build

3. אם שניהם עוברים, הפעל את הבוט:
   npm run dev

4. פתח את הבוט שיצרת בטלגרם ושלח:
   /start

5. אם ADEL_ADMIN_TELEGRAM_ID נכון, תקבל הודעת welcome של owner.


בעיות נפוצות
-------------

בעיה: הבוט לא עונה בכלל.
פתרון:
- ודא ש-npm run dev עדיין רץ.
- ודא ש-TELEGRAM_BOT_TOKEN נכון.
- ודא שלא יש עוד תהליך אחר שמריץ את אותו bot token.

בעיה: הבוט עונה אבל לא מזהה אותי כבעלים.
פתרון:
- בדוק שוב את ADEL_ADMIN_TELEGRAM_ID מול @userinfobot.
- מחק data/adel-demo.db והרץ מחדש.

בעיה: הבוט אומר שיש בעיה עם OpenRouter.
פתרון:
- ודא שה-OPENROUTER_API_KEY נכון.
- ודא שיש קרדיט פעיל.
- אפשר זמנית להחליף מודל ב-.env למודל זול יותר אם צריך.

בעיה: לקוח מקבל הודעה שלא מקושר לעסק.
פתרון:
- מהחשבון של הבעלים שלח:
  /claim <CLIENT_ID> client


מה לא צריך למחר
---------------

- לא צריך Supabase.
- לא צריך WhatsApp.
- לא צריך Google Calendar אמיתי.
- לא צריך PDF.
- לא צריך dashboard.

לדמו מחר מספיק:
- Telegram bot token
- Telegram admin ID
- OpenRouter key
- SQLite מקומי
